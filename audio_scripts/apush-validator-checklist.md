# Validator Checklist — the user's own review patterns (2026-10-06)

Distilled from the user's line-level reviews of U3-E8 v2 → v3 → v4.
Every Layer-2 and Layer-3 validator runs this list IN ADDITION to the guide.
A script that passes the gates but fails any item below is not lock-ready —
the user caught 20 issues in a v3 that was 12/12 green with both agent layers passing.

## Quote and disclosure integrity
- [ ] Every line presented as a historical figure's "actual words" matches the
      real wording ("smelt," not "smelled"). If the wording is reported rather
      than transcript-verified, the disclosure says so.
- [ ] The disclosure separates real quotes from dramatized debate dialogue,
      and the separation is honest about which is which.

## Exchange logic (debates especially)
- [ ] Every attack lands on something that actually happened in the script.
      A "your own side credits the wrong author" jab is broken if the script
      never credited the wrong author.
- [ ] No character quotes a line that was cut in a previous version.
- [ ] No reply repeats what the same character just said two turns earlier.
- [ ] Interruptions and reactions are ordered correctly: a reaction follows
      the line it reacts to, never a line not yet spoken.

## Time-travel
- [ ] Historical voices stay in their year. A figure speaking in 1788 cannot
      know 1789/1790 outcomes. Future knowledge comes only from modern voices
      (Marcus, Maya) — and the voice framing must make that clear.
- [ ] Chronology claims verified: who wrote alongside whom (Brutus ran
      ALONGSIDE the Federalist Papers; it did not "take them apart"),
      paraphrases match the actual argument (Brutus: a republic can't hold
      over so large a territory).

## Stimulus and exam devices
- [ ] Stimulus quotes are exact. Splices are marked with ellipses.
- [ ] Self-test model answers never speak "Claim:/Evidence:/Reasoning:"
      labels aloud — the CER shape must be carried by natural connective
      tissue, never spoken labels. TTS reads everything literally.
      (Frozen 2026-10-06: user ruled spoken labels are bad TTS, no exceptions —
      the locked U3-E8 exemplar was fixed post-lock to comply.)
- [ ] Bonus questions are AP-shaped (e.g. "How many states did Article VII
      require?"), never trivia (e.g. "which state was ninth?").
- [ ] Timing traps are explicit, not implicit ("not written in Philadelphia,
      added in 1791 as the price of ratification").

## Claims and framing
- [ ] Promise directions are correct (the WINNERS' promise TO the losers —
      get the direction right, then check it again).
- [ ] No overclaims: "every states' rights fight" → "many." Verdicts are
      hedged or both-sided; AP rewards both sides.
- [ ] Closers rebut, not just confess. A closing statement answers the
      opponent's charge.
- [ ] "Technically true but misleading" = wrong. Check labels,
      characterizations, and whether source nuance survived into the script.

## Content completeness
- [ ] The figure's REAL strongest argument is present, not a muddled
      substitute (Henry's wartime-emancipation fear, not a dodge).
- [ ] Slavery is a live factor where it was one, not a moral aside.

## Voice (de-slop)
- [ ] No parallel mirror pairs ("Bigness isn't the danger. Bigness is the
      cure." / "They tell you bigness is the cure...").
- [ ] No "Tell me" / "answer me this" tics (max one per script, and only if
      it earns its place).
- [ ] No triplets or aphorism chains ("unnecessary, dangerous, or essential" /
      "A promise, not a clause" / "leash on power / license for it").
- [ ] No modern-op-ed phrasing in historical mouths ("Do abstractions fear
      the people?", "machine for making citizens irrelevant").
- [ ] Funny true details used where they exist (Hancock's gout: litter,
      flannel) — attributed when the humor rests on inference ("his enemies
      swore it was convenient").

## Structure and fun
- [ ] Anecdotes sit at the right point in chronology; flashbacks are framed
      as flashbacks ("Rewind three weeks...").
- [ ] Jokes land where energy sags, never interrupting the middle of a
      theory exchange.
- [ ] One-line cultural nods (the Hamilton musical) nod — they don't accuse.

## Numbers
- [ ] Real spoken-word count run (pause tags stripped). Header, cold-open
      promise, and actual agree. Pauses are counted in the experienced-time
      promise (guide: runtime = speech + pause silence).
- [ ] Number density reduced; audio can't carry a facts conveyor.
