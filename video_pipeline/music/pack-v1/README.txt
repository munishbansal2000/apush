APUSH + Podcast Music Pack v1
=============================
Format policy: beds = MP3 192kbps/44.1kHz, stings = WAV.
All are -14 LUFS source masters, instrumental, no vocals.
Bed MP3s were transcoded from the WAV masters (kept offline, not in git).
If any bed loop ticks at the loop point, re-render that bed as WAV.
