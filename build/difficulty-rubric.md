# Difficulty Rubric — APUSH (recalibrated 2026-10-02)

Munish's call, same treatment ap_stats got. Grounded in the 2025 Chief Reader
data (518k students, mean 3.30): sourcing 0.39/1, complexity 0.15/1,
evidence-beyond-documents 0.47/1 — the skills students actually fail.
CB publishes NO numeric easy/medium/hard thresholds; difficulty is
design-intent. The strict "multi-step reasoning only" bar is RETIRED — it
contradicts CB's empirical data on what students get wrong.

## HARD — the item measures a skill students demonstrably fail
An item is HARD if it requires at least one of:
1. **Sourcing analysis** — POV / purpose / audience / historical situation of a
   source; judging a source's reliability, intent, or limits (0.39/1).
2. **Complexity** — qualifying or modifying an argument, recognizing limits of
   evidence, weighing competing interpretations (0.15/1).
3. **Evidence beyond the documents** — identifying what outside evidence would
   support, qualify, or undermine a claim (0.47/1).
4. **Claim/argument evaluation** — judging whether a historical argument is
   valid, with distractors built from documented student misconceptions
   (presentism, monocausation, chronology-as-causation, overgeneralization
   from one region/group, confusing correlation with motive).
5. **Periodization judgments** — turning-point / continuity-vs-change calls
   with competing evidence on both sides.
6. **Contextualization requiring synthesis** — placing an event in a broader
   regional or global context where distractors are plausible wrong contexts,
   not filler.
7. **Multi-step / chained reasoning** — a later inference depends on an
   earlier result.

Sharpened rule (the ap_stats gray-zone lesson): an evaluation/sourcing item
counts as HARD via 1–4 only if ALL of:
(a) >=2 distractors each encode a DISTINCT documented misconception
    (not the same misconception reworded, not filler/off-topic options,
    not merely wrong dates/names);
(b) the stem does not telegraph the answer — no cue word or phrase that
    hands the discrimination to the student;
(c) the concept being tested is not named in the stem as a direct-application
    cue (a stem that says "which turning point" and tests turning-point
    identification is application, not evaluation).

## MEDIUM — single-step execution or straightforward application
Identify-from-stimulus, straightforward cause-and-effect, apply a definition,
one-step inference with clear textual support, single discrimination
(one misconception distractor + fillers).

## EASY — recall or telegraphed
Pure one-step recall with blatantly false distractors, or the item gives
itself away: longest-option tell, cue words, answer identifiable by a
definitional catchphrase alone without confronting competing claims.

## Rules
- Change ONLY the `difficulty` field. Never touch stems, options, keys, or
  explanations in this pass (keys were already blind-audited).
- Judge the item as written, not its topic's reputation.
- Rate BLIND: do not look at the current tag while rating.
- When borderline, prefer the lower label. Munish's law: honest labels.

## No quotas
Rate honestly first, then check the mix. If any period would land at 0% hard,
report it as a content gap — do not inflate labels to satisfy the validator.
